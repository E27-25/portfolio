# Watin Promfiy — Portfolio

Personal portfolio of **Watin Promfiy** (E27-25): AI Engineer · Data Scientist · Data Engineer.

A static site (HTML, CSS, vanilla JS) with self-hosted fonts, deployed on Vercel.

- `index.html` — all content
- `styles.css` — industrial sci-fi UI (lilac-white panels, violet-black, lavender accent)
- `main.js` — reveal animations, section tracking, awards carousel, mobile menu
- `fx3d.js` — WebGL objects (hero orbit core, section objects, contact globe) and card tilt, bundled with [three.js](https://threejs.org) (MIT). Globe land data: [Natural Earth](https://www.naturalearthdata.com/) via world-atlas (public domain).
